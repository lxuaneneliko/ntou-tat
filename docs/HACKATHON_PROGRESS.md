# 海洋黑客松增修進度

更新日期：2026 年 10 月 12 日。

本紀錄對應此分支的 Android／網頁增修原始碼，屬開發與驗證進度，不是正式發布公告。保留原有 iOS 程式，不以 Android 測試結果宣稱 iOS 已完成。

## 已加入的增修

### 外觀與導覽

- T 字圖示取代學校校徽，調整 Android 圖示與啟動畫面的比例。
- 淺色／深色與預設配色，自訂詳細色彩。
- 底部導覽可替換「其他」中的入口；「其他」位置固定。主選單入口不再顯示返回「其他」按鈕。
- 外觀設定獨立入口、學生身分卡版面與照片比例調整。

### 課表、行事曆與成績

- 行事曆月／週切換、色彩與空間配置調整。
- 同一事件跨日期連成事件列；課程顯示由使用者切換。
- 課程詳細資訊與離線開課資料讀取；包含既有公開的歷年課程資料，不等同每堂課的詳細教學大綱已完整蒐集。
- 還原學校原始課表，保留自訂新增課程流程。
- 在既有進階英文欄位加入修畢／抵免選項，依選擇調整學分分析；不混同大一英文。分析仍需依使用者適用學年度及學校核定結果確認。

### 信箱與 Android 小工具

- Mail2000 快取上限 1000 則、滑動載入更早郵件。
- 信件詳情返回時恢復原捲動位置。
- Mail2000 一天最多一次新信通知；實際執行時間受系統背景排程影響。
- 桌面今日課表小工具與可選課表通知。鎖定畫面第三方小工具依手機系統支援，不保證所有裝置可直接加入。

### 校園活動與揪團

- 活動入口替代預設行事曆位置，行事曆保留於其他／可自訂入口。
- 各主要頁面快報循環浮現，縮小上方區域、不顯示筆數／暫停按鈕，保持一致高度。
- 活動與原始圖片從既有活動 API 更新，保留來源與報名連結。
- 學生揪團置頂；App 內發起、加入、退出、編輯、取消與檢舉，不要求另登入活動網站。
- 利用現有 AIS 登入狀態向固定活動後端核對學號；不傳 AIS 密碼、不保存收到的 AIS Cookie，不採用信任客戶端學號的假驗證。

## 仍需驗證或補齊

1. 使用真實手機確認 AIS 背景核對成功，再以兩位同學實測發起、加入、退出與取消。
2. 手機背景收信通知、登入過期／重新登入、斷網與帳號切換。
3. 公開揪團使用規則、會員／內容檢舉、封鎖及持續處理流程。
4. 會員資料刪除入口、資料保留期限、公開隱私政策與 Play Console 資料安全性聲明。
5. 正式發行前沿用原正式 App 套件識別與簽章金鑰，另行完成正式版整合、版本代碼及商店審核。

活動平台與其 Cloudflare 後端目前是另一個本機／部署專案；本分支記錄 TAT 端串接，不包含活動平台資料庫、會員資料或維護作業的完整專案。活動 API 可持續更新，但活動網站的所有資料不代表已全面蒐集或核實。
